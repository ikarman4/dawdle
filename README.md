# DAWdle

DAWdle is a daily browser composition game. Every UTC day, everyone hears the same 20 seconds of a real song on YouTube, then plays a version with sampled instruments. Five tries. The best percentage is kept.

The catalog is the Billboard year-end top 50 from 1973 through 2022. The videos are embedded, not rehosted. Sampled instruments are excerpts of Fluid (R3) GM by Frank Wen, MIT license.

```bash
npm install
npm test
npm run dev
npm run build
```

The game is hosted at https://ikarman4.github.io/dawdle/. Routes are `#play`, `#you`, and `#leaderboard`.
